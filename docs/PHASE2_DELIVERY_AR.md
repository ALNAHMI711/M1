# المرحلة الثانية لتسليم M1

أضيفت محاكاة PAPER نقدية محفوظة ومصالحة ذرّية وعزل الأسواق والبيئات.
الكود التنفيذي الذي اختُبر لهذه الدفعة هو
`78a00ba568ff71d0517db87a31d35405c48f1711`؛ تحديث هذه الوثيقة بعده توثيقي.
LIVE مغلق، وطلب الدمج مسودة لم يُدمج إلى main.

## التنفيذ

- PAPER: نقد ومراكز ومتوسط تكلفة ورسوم وربح/خسارة محققة وإيصالات،
  بمدخلات Decimal وحدود خادم وسجل CSV خاص بكل مستخدم.
- منع التكرار والإنفاق المتزامن ضمن معاملة واحدة؛ المخاطر من الرصيد
  والمراكز المحفوظة، شامل رسوم الوقف والهدف المخططتين، لا قرارات العميل.
- SELL يغلق كمية مملوكة فقط، لا اقتراض أو رافعة أو بيع مكشوف.
- إعادة التشغيل والاستعادة تحفظ PAPER؛ الاستعادة تبطل الدخول وتفعّل الإيقاف.
- حالات الأوامر والتعبئة والوقت تُحدّث ذرّيًا؛ لا تراجع لحالة نهائية
  أو تعبئة تراكمية، ولا خلط SPOT/USDM أو TESTNET/LIVE.
- عميل Spot LIVE أو غير موسوم مرفوض قبل استعادة أو متابعة Stream.
- السجلات القديمة بلا سوق UNKNOWN لا تُخمن؛ تظل معزولة حتى
  `include_quarantined=true` للمصالحة القرائية الصريحة، لا إعادة إرسال أمر.
- واجهة PAPER تضم شراء/بيع وإعادة الإيصال والحساب وCSV وصلاحيات الأدوار.

## نتائج التحقق

محليًا اجتازت 3342 اختبارات TypeScript، و307 اختبارات Python على 3.11،
وخمس اختبارات Playwright ضد Backend محلي فعلي دون اتصال تنفيذ بورصة.
اجتازت typechecks الثلاثة والبناء وcompileall وتدقيق npm وpip للاعتماديات.
ظهر تحذير إهمال واحد من Starlette/httpx، لا فشل اختبار.
حجم مكتبة المؤشرات المؤجلة كبير، ولا تُحمّل حتى طلب المستخدم.

اجتاز بناء وتشغيل Docker/Compose/Caddy في CI:
الواجهة وملفاتها، الدخول، شراء/بيع PAPER والرسوم/PnL ومنع التكرار،
CSV، بقاء الجلسة والأرصدة بعد إعادة تشغيل Backend، الإيقاف،
وتسجيل خروج محفوظ عبر إعادة تشغيل أخرى
([تشغيل docker-check](https://github.com/ALNAHMI711/M1/actions/runs/38018329088)).

نجحت الفحوصات الخمسة على SHA التنفيذي المذكور:
[CI](https://github.com/ALNAHMI711/M1/actions/runs/38018329106)،
[backend-check](https://github.com/ALNAHMI711/M1/actions/runs/38018329104)،
[browser-check](https://github.com/ALNAHMI711/M1/actions/runs/38018329087)،
[security-audit](https://github.com/ALNAHMI711/M1/actions/runs/38018329094)،
[docker-check](https://github.com/ALNAHMI711/M1/actions/runs/38018329088).
راجع أحدث SHA قبل أي دمج، ولا تعتمد نتيجة على SHA أقدم بدل الأحدث.

كان أول فحص للحاويات قد فشل بسبب اختلاف Host الاختبار عن إعداد Caddy.
صُحح إلى localhost وأضيف تحقق من مضمون readiness قبل إعادة التشغيل الناجحة.
تحتفظ GitHub Actions بالتاريخ الفاشل ولا يُخفى.
