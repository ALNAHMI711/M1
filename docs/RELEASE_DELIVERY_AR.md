# تسليم M1: منصة تحليل ورقابة محسّنة

## نطاق التسليم

تحديث المرحلة الثانية: أضيف محاكي PAPER نقدي محفوظ، ومصالحة ذرّية
مع عزل الأسواق والبيئات. راجع `docs/PAPER_SIMULATION_AR.md`.
البنود أدناه تشمل الدفعتين؛ LIVE مغلق دائمًا.

الأساس `ALNAHMI711/M1` عند commit
`19a968238be2475134d289b2161e54ad88f6731b` من فرع
`integration/trading-platform-2026-10-07` وطلب الدمج #3.
العمل الجديد على `completion/security-delivery-2026-10-10`.
لم يُدمج إلى main ولم يُفعّل التداول الحقيقي.

هذه نسخة قابلة للتشغيل والتحقق محليًا للتحليل والمراقبة، لا اكتمال لكل
أنواع التداول المطلوبة ولا شهادة جاهزية إنتاج. لا توجد محولات وهمية
أو ادعاء باختبار خارجي لم يُنفّذ.

## التحسينات المنفذة

- قفل npm صالح و`npm ci` في CI؛ حفظ مصادر المؤشرات والتراخيص والاختبارات.
- إغلاق تجاوز `live_enabled=True` في المسار القديم؛ LIVE مرفوض دائمًا.
- اشتراط محول TESTNET صريح عند حدود استدعاء الاختبارات.
- إشارات finite واختبارات إضافية لرفض NaN وInfinity في بوابة المخاطر.
- جلسات JWT دائمة بمتطلبات issuer/audience/expiry/jti وإبطال محفوظ.
- مستخدمون بأدوار، وإبطال جلسات عند تغيير كلمة المرور أو الدور.
- مفتاح إيقاف محفوظ وتعديل ADMIN وسجل تدقيق.
- حد معدل محفوظ، وأجسام bounded حتى chunked، وHost checks ورؤوس أمان.
- إدراج ذرّي للإشارات يمنع قبول التكرار المتزامن.
- allowlist لأصل ومسارات Binance، ومنع redirects والسحب والتحويل والأوامر الحقيقية.
- نسخ SQLite متسق واستعادة جديدة تبطل الجلسات وتفعّل الإيقاف.
- واجهة RTL فاتحة/داكنة تدعم الهاتف، وDEMO موسوم بوضوح وتصدير CSV.
- مكتبة مؤشرات تُحمّل عند الطلب، ومعالجة خطأ السوق وسباقات التحميل والانقطاع.
- لوحة دخول وحالة وتدقيق وتحقق من إشارات ومفتاح إيقاف؛ لا زر تداول.
- لوحة PAPER لشراء/بيع افتراضي نقدي، ومراكز ورسوم وربح/خسارة
  وإيصالات محفوظة وسجل CSV خاص بكل مستخدم.
- احتساب المخاطر على الخادم وتضمين رسوم الدخول والخروج المخطط في RR؛
  لا بيع على المكشوف، ولا رافعة، ولا وقف/هدف تلقائي.
- مصالحة ذرّية لا تقبل تراجع التعبئة أو الحالة النهائية أو الأحداث القديمة؛
  عزل SPOT وUSDM وTESTNET ورفض عميل Spot LIVE أو غير موسوم.
- فحص Spot Testnet ثابت من exchangeInfo قبل order-test، ومسار عام
  دون مفاتيح وCLI قرائي فقط؛ لا تحويل لفحص ثابت إلى شهادة جاهزية إنتاج.
- Docker/Compose وCaddy وبيئة نموذجية ودليل تشغيل واختبارات متصفح.

## أدلة الاختبار

- `npm test`: 3342 اختبارًا ناجحًا.
- `pytest -q` على Python 3.11: 365 اختبارات ناجحة.
- Playwright: 5 اختبارات ناجحة، منها Backend وPAPER فعليان محليان دون بورصة.
- typecheck للمكتبة والواجهة، وبناء المكتبة والواجهة: ناجحة.
- `npm ci --ignore-scripts` و`npm audit`: نجاح، دون ثغرات معروفة في الفحص.
- `pip-audit` لملفي runtime/test المقفلين: دون ثغرات معروفة في الفحص.
- فحص الهاتف وسطح المكتب والمظهرين: دون overflow أفقي؛ لوحة التحكم قابلة للتمرير.
- حجم JavaScript الأولي للبناء حوالي 241 KB غير مضغوط؛ مكتبة المؤشرات
  المنفصلة حوالي 3.58 MB وتُحمّل عند الطلب. يبقى تحذير حجم المكتبة الكبيرة.
- تحذير إهمال httpx في Starlette TestClient موجود، ولا يمنع نجاح الاختبارات.
- فحص CI الأول كشف setuptools قديمًا في صورة runner؛ أضيف تحديث
  `setuptools>=83.0.0` في CI وDocker وتعليمات التشغيل، دون تجاهل الثغرة.
- كشف CI سباق WAL عند فتح قاعدة جديدة من عدة خيوط؛ عولج الانتقال
  بانتظار محدود للقفل، مع اختبار عشر قواعد باردة وتزامن حقيقي.

نتائج CI البعيدة يجب مراجعتها على commit المنشور نفسه ولا تُستنتج من المحلية.
نجاح اختبارات نقل وهمية لا يثبت تكامل Binance Testnet الحقيقي.

## مصفوفة الجاهزية

| الوحدة | الحالة |
|---|---|
| الشموع والمؤشرات | تعمل؛ بيانات السوق العامة تتطلب الوصول إلى Binance |
| DEMO | بيانات مصطنعة للعرض فقط، لا تعبئة مالية |
| PAPER | تعبئة نقدية افتراضية محفوظة بسعر المستخدم؛ ليست تعبئة بورصة |
| المصادقة والجلسات والرقابة | منفذة ومختبرة محليًا |
| Spot order-test | تحقق صيغة Testnet؛ غير مختبر بمفتاح فعلي |
| Spot preflight | فحوص ثابتة محلية؛ HTTP 451 يمنع إثبات البيانات الحية من بيئة التسليم |
| تنفيذ Spot الحقيقي | مغلق ولا يوجد مسار إرسال أمر حقيقي |
| USDⓈ-M | وحدات أحداث واستعادة؛ لا اعتماد تكامل فعلي أو LIVE |
| COIN-M والهامش وAlpha والأسهم | محولات التنفيذ غير مكتملة ومغلقة |
| Docker/Compose | البناء والتشغيل وإعادة التشغيل نجحت في CI المعزول |
| TLS والسحابة | تشغيل إنتاجي وإصدار شهادة ومراقبة غير مثبتة |
| IP وصلاحيات API | يحتاج حساب البورصة وIP الخادم؛ لم يُتحقق |
| مراقبة وجدولة نسخ وتنبيهات | إعداد تشغيلي مطلوب على الخادم |
| إنتاج تداول | غير جاهز؛ CI وحده لا يكفي |
