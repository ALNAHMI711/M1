# Render free trial deployment

This configuration deploys only the FastAPI backend from `backend/Dockerfile`. Render terminates HTTPS; Caddy and Docker Compose are not used.

## Ephemeral storage warning

The free service stores SQLite at `/tmp/m1.sqlite3` and creates the Testnet credential-encryption key at `/tmp/m1_testnet_encryption_key` on first startup if missing. Both paths are on the container's temporary filesystem. **Data, sessions, audit history, paper balances, settings, and encrypted credentials may be lost when the service restarts, redeploys, or is replaced.** The encryption key is regenerated if lost, so previously encrypted credentials would no longer be decryptable. Do not store real exchange credentials or use this as a production trading service.

## Safety defaults

- `M1_TESTNET_ORDER_SUBMISSION_ENABLED=false`
- `M1_AUTH_SECRET` is generated by the Render Blueprint.
- No Binance API credentials are configured.
- The backend rejects LIVE execution; Testnet remains off by default.
- Set `M1_ADMIN_PASSWORD_HASH` as a secret environment variable in Render before attempting login. It must be a `pwdlib`/Argon2 password hash, not a plaintext password.

## Health and port

Render checks `/ready`. Uvicorn binds to `0.0.0.0:$PORT`, with port 8000 as a local-development fallback.
